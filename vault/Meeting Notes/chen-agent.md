# Chen Agent — חוקרת הרשת

## Overview

חן היא ה-sub-agent השלישית והאחרונה בצוות של ראובן — סוגרת את שלישיית המומחים (יעל-כתיבה, יובל-עיצוב, חן-מחקר). מוגדרת ב-`.claude/agents/chen.md` עם הכלים `WebSearch, WebFetch, Read, Write, Edit, Glob, Grep` (אין Bash — היא לא צריכה לקרוא ל-API חיצוני, רק לרשת הפתוחה). ה-flow שלה: בקשה מראובן → בדיקת זיכרון ב-`chen/Memory/searches.md` → WebSearch (2–4 שאילתות) → סינון לפי קריטריוני איכות → WebFetch על 1–3 מקורות → שמירת המקור הנבחר ב-`Content/<YYYY-MM-DD>-<slug>.md` עם frontmatter מלא + תיעוד בלוג חיפושים → דיווח לראובן. **לא קוראת ליעל** — מכינה את הקרקע, ראובן מחליט אם להפעיל את שרשרת הכתיבה.
